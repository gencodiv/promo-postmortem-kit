# Promo Postmortem Kit

A lightweight toolkit for understanding what a retail promotion actually changed.

## Why this exists
Post-promo review is often shallow. Teams see sales movement but not the full picture:
- volume lift
- margin change
- stock pressure
- post-promo fade

This project is designed as a small but useful postmortem starter.

## First release scope
- before/after comparison table
- margin delta summary
- simple stock-pressure signal
- post-promo commentary block

## Stack
- Python
- pandas
- Streamlit

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```
